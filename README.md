# QuantumSushi (Thomas H.)

Master's student in computer science at EURECOM (Sophia Antipolis), specializing in embedded systems and low-level programming.
My work spans hardware/software co-design on SoCs, microarchitecture and side-channel security, FPGA design in VHDL and ML deployment on embedded platforms.

Also a tech enthusiast, self-hosting enjoyer and avid learner. You will find here all my personal projects and work!

## Domains

Embedded systems, low-level programming, machine architecture, FPGA design, hardware/software co-design, microarchitectural security, embedded ML/AI, self-hosting and networking.
